# Cash Harmony

Build a Cash Flow & Financial Management App with Supabase Auth and Lovable Cloud backend. Features:
- Auth (Email & Password login/register, protected routes).
- SaaS dashboard layout with sidebar, header (user profile, logout, date range filter), and KPI cards (Total Pemasukan, Total Pengeluaran, Laba Bersih in IDR).
- Recharts visualizations: trend chart for Income vs Expenses and a category breakdown pie chart.
- Transaction management: modal form to create/edit transactions (type, IDR amount, category, date, title, notes), filterable data table, green/red badges, delete/edit actions, and toast notifications.
- Clean slate/zinc aesthetic with indigo accents and responsive design.

This project was built with [Lovable](https://lovable.dev).
